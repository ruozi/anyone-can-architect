# 文档设计：data-analysis

## 1 文档定位

面向运营数据的分析者，说明各项指标的分析方法与可选的可视化方式
同一份原始数据可以用于多个指标的分析

## 2 文档结构

第一章为「指标汇总」，用表格列出指标、含义与对应分析章节的链接
从第二章起，每章讲解一个指标

每个指标包含以下内容

| 内容 | 要求 |
| --- | --- |
| 分析方法 | 引用所需的原始数据定义，说明指标的计算与分析过程 |
| 可视化 | 按需说明展示方式，也可提供 HTML mockup |

## 3 行文步骤

1. 整理需要分析的指标，编写指标汇总表
2. 为各指标分别编写分析章节，说明所需数据与分析过程
3. 按需补充可视化方式或 HTML mockup
4. 补齐汇总表到各指标章节的链接，按[检查条件](#5-检查条件)检查文档

## 4 示例

第一章汇总「订单量」与「成交金额」，分别链接后续分析章节
「订单量」一章引用订单数据定义，说明统计范围、筛选条件与计数过程
如需观察变化趋势，可说明按日期展示折线图，或给出对应的 HTML mockup
「成交金额」另起一章说明自己的分析方法

## 5 检查条件

- [ ] 第一章以表格汇总指标，包含含义与有效的分析章节链接
- [ ] 每个指标均有独立章节，所需原始数据定义能够定位
- [ ] 分析方法能够说明指标的计算与分析过程
- [ ] 提供可视化时，展示内容与对应指标及分析方法一致
