# 文档设计：ssot

## 1 文档定位

登记项目实际采用的外部依据及其出处

## 2 文档结构

每个业务主题一个 [chapter](../../CONTEXT.md#chapter)
chapter 标题使用业务主题名称
chapter 下直接列依据条目

```text
# 项目外部依据

## 1 <业务主题>
- <依据条目>
- <依据条目>

## 2 <业务主题>
- <依据条目>
```

每项登记来源名称、真实链接或原件路径及一句内容概述
采用的内容依赖特定版本或日期时，注明版本或日期
内容概述说明来源提供什么
随仓保存的外部原件使用相对路径引用

## 3 行文步骤

1. 从设计或规范中识别实际采用的外部依据
2. 查找原始来源，核验其内容是否支持项目采用的规则
   按需确认采用的版本或日期
   无法核实来源或来源内容相互冲突时，与开发者确认采用的依据
3. 按[文档结构](#2-文档结构)将已核实的依据归组并登记
4. 在采用依据的正文中引用 SSOT 的对应条目
   说明该依据中实际采用的规则
5. 项目采用的依据变化时，更新对应条目、受影响的正文与引用

## 4 示例

```markdown
# 项目外部依据

## 1 版本管理
- [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)：按版本记录显著变更，区分未发布与已发布内容
```

## 5 检查条件

- [ ] 每项都是项目实际采用的外部依据
- [ ] 出处能够定位已核实的来源
- [ ] 需要限定版本或日期的依据已注明相应信息
- [ ] 章节与条目符合[文档结构](#2-文档结构)的规定
- [ ] 同一依据没有重复登记
- [ ] 采用依据的正文引用 SSOT 的对应条目
- [ ] 正文说明该依据中实际采用的规则
- [ ] 项目采用的依据变化后，对应条目、正文与引用已同步更新
