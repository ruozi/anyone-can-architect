# Shared Axioms

> Fundamental principles of Anyone Can Architect doc design, non-negotiable hard constraints
> Both docs sit directly in this directory, this table defines where they are injected, and `scripts/build-skills.sh` and `scripts/setup.sh` select them by name from this table

| Axiom | File | Injection | In One Sentence |
|---|---|---|---|
| Writing | [writing.md](writing.md) | design "Doc Writing" chapter<br>walkthrough / review / repo-audit body<br>Top of each doc design | Doc structure, concepts and references, chapters and sections, lines and tables, characters — "how to write" |
| Completeness (Boil the Ocean) | [boil-the-ocean.md](boil-the-ocean.md) | specify "Solution Design" chapter | If you can achieve 100%, do not settle for 80% |

Skill-level axioms apply only to skills with design responsibilities, implement / release / feedback handle execution only and receive no injection
