# Doc Design: guideline

## 1 Purpose

Define the applicability conditions, decision criteria, and usage requirements for normative provisions

File organization for specification repositories is covered by the [guideline repo type](../repo-types/guideline.md)

## 2 Writing Requirements

Normative provisions should specify applicability conditions and decision criteria

For mandatory constraints, explain the consequences of noncompliance and how to handle it

Lists should specify whether they cover the full scope or provide examples
Lists that cover the full scope should specify how to handle unlisted cases
